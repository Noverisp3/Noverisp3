### 🧠 About Me
A 15-year-old passionate developer diving deep into the matrix of systems programming, operating system kernels, and hardware optimizations. I prefer raw performance, bitwise operations, and low-level control over heavy abstractions.

* 🛠️ **Current Focus:** Android kernel development, memory compression architectures, and custom I/O schedulers.
* 🛡️ **Interests:** Cybersecurity, UEFI/Firmware analysis, and retro-hardware optimization.
* ☕ **Philosophy:** *"If it's not fast, optimize it. If it's still not fast, write it in Assembly."*
